# Giáo Án Địa Ngục

Ứng dụng ghi mức tạ, lộ trình tăng tạ theo tuần, gợi ý nhóm cơ theo độ hồi phục, nhiều người tập trên một máy, chạy offline trên điện thoại.

- Thư mục gốc: app (GitHub Pages).
- `push-server/`: máy chủ gửi thông báo hết giờ nghỉ (Cloudflare Workers).

Dữ liệu tập luyện lưu trên điện thoại của người dùng, không lưu trong repo này.
