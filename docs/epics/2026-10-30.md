## Hạng mục 1 — Nghỉ xong sau set cuối: báo bài kế tiếp

### Bối cảnh
> Sau khi hoàn thành đủ các set trong bài, thông báo "Hết giờ nghỉ · Vào set tiếp: Đá đùi" phải đổi thành bài kế tiếp mới đúng logic.

### Nguyên nhân
`'set-done'` luôn gọi `startRest(restOf(ex), shortName(ex.name))` với tên **bài vừa tập**, không xét bài đó đã xong hết set chưa.

### BR
BR-43.1–43.3 (xem `docs/BR.md`).

### SA
`restNext`, `restMsg` (hàm thuần), `rest.msg`; nút `.nextex` dùng chung `restNext` nên thứ tự bài kế tiếp trong hộp báo và trên màn hình luôn khớp. Lời báo khi bài còn set giữ nguyên (test `rest.spec`, `notify.spec` không đổi).

### Test
- `tests/test_nghi_bai_tiep.mjs` đỏ trước (thiếu hàm) → xanh 9/9; trong `tests/chay.sh` (xanh 10/10).
- Bấm thử trên Chromium khổ iPhone (đồng hồ giả): sau set 1 Đá đùi → "Vào set tiếp: Đá đùi"; sau set cuối Đá đùi → "Sang bài tiếp: Móc đùi nằm · set 1", nút "Sang bài tiếp", bấm → mở bài Móc đùi nằm; xong bài cuối → không bật đồng hồ nghỉ; không lỗi JS.
- Playwright cần chạy trên local: `rest.spec.mjs`, `notify.spec.mjs`, `session.spec.mjs`.
